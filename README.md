# Fashion Finder :dress:

This repository presents the development of an AI-based app, *Fashion Finder*, designed to revolutionize the fashion shopping experience by bridging the gap between consumers and their desired fashion items. 

## Features
- Utilizes cutting-edge technologies such as the **Microsoft Azure Custom Vision API** and **Shopify API**.
- Enables users to upload images of clothing items they like and subsequently find the nearest match in a Shopify store.
- Developed using the **Dart** programming language and **Flutter** framework.
- Ensures cross-platform compatibility and a visually appealing user interface.
- Caters to a wide audience on both **Android** and **iOS** devices.

## Goal
Fashion Finder aims to provide a personalized, efficient, and enjoyable shopping experience, leveraging AI to transform the way users discover and purchase clothing.
